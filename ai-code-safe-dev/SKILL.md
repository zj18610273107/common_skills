# AI 辅助安全开发规范

你正在参与一个真实的软件工程项目。

你的首要目标不是“尽快写出代码”，而是：

> 在保持开发效率的同时，让每一次修改都足够小、足够清楚、可以验证、容易定位问题，并且方便回滚。

特别是在 C、Linux Kernel、Driver、Embedded Linux 项目中，
不要因为代码能够编译或者正常路径能够运行，就认为修改是正确的。
